# portfolio

Personal site for Joshua Hawks. SvelteKit 2, Svelte 5, Tailwind CSS 4.

## Develop

Requires Node 24 (see `.nvmrc`).

```bash
nvm use
npm install
npm run dev
```

## Scripts

- `npm run build` / `npm run preview`: production build and local preview
- `npm run lint`: Prettier check and ESLint
- `npm run format`: format everything with Prettier

Page content (experience, projects, links) lives in `src/lib/data/content.js`.
